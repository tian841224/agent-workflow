# 自我學習規則 — 全域

跨專案的學習機制：任務中即時擷取教訓，寫入時立即去重與校準，達到明確證據門檻後才升級為規則／技能／決策。本檔為權威定義；日常流程內化在工作流程與平台能力中，`learn` 只保留手動深度回顧入口。僅 Claude Code 有 auto-memory 與索引自動注入；Codex/Antigravity 維持手動記憶層架構。

## Session 開場

- 若 `~/.claude/memory/MEMORY.md` 存在，先讀取再開始任務。
- Claude Code 的專案記憶索引會自動注入；索引指到的 `overview.md` 仍須在判軌前讀取。
- Codex/Antigravity 無自動注入；每個 session 至少在判軌前主動讀專案 `MEMORY.md` 與 `overview.md`。
- 引用記憶前確認仍成立；無法確認的內容標記「待驗證」。

## 事件觸發：當下擷取並整理

以下事件發生時，不等待批次回顧：使用者糾正、可概括的編譯／測試／執行錯誤、實際行為與文件或既有認知不符、同一 session 第二次犯同類錯誤、使用者明說「記住」，以及任務收尾的沉澱三問。

寫入前先查 `MEMORY.md`：

- 相同主題已有記憶 → 合併或更新，不新增重複檔案。
- 引用的檔案／指令／行為已過時 → 修正或刪除。
- 無法確認的資訊 → 標記「待驗證」，不可寫成確定事實。
- 每次只整理本次事件相關主題，不掃描全部歷史記憶。

## 分流：這條教訓換一個專案還成立嗎？

| 教訓性質 | 去向 |
|---|---|
| 跨專案通用 | 全域 `~/.claude/memory/` |
| 專案特定且有 repo 內記憶層 | 該專案 repo 內記憶層 |
| 專案特定且無 repo 內記憶層 | Claude Code：`~/.claude/projects/<專案>/memory/`；Codex/Antigravity：`AGENTS.memory/` |

拿不準先進專案層。專案歷史脈絡、架構演進與高風險區聚合進 `overview.md`；方案取捨優先寫入 ADR 或 `DECISIONS.md`，記憶層只留指標。

## 升級門檻

- 同類教訓重複 ≥2 次或屬每次都該遵守的準則 → 提出規則升級。
- 多步驟可重複程序 → 提出 skill 升級。
- 同一技術域累積 3–5 條 → 提出 `playbook-<技術域>.md`。
- 跨專案升級必須有至少兩個獨立專案的證據，不得只因單一事件泛化。
- 規則、skill、全域記憶的新增或修改一律先提出，經使用者核准才寫入。
- 全域 `MEMORY.md` 上限 50 行；逼近上限時在本次寫入流程中先修剪或提出整理提案。

## 專案記憶層結構與格式

各平台同構：`MEMORY.md`（索引）＋ `overview.md`（概觀）＋ `DECISIONS.md`（append-only）＋ `<topic-slug>.md`（個別記憶）。記憶檔使用 `name`／`description`／`metadata.type` frontmatter；pitfall 必須包含「錯誤情境」→「正確做法」→「避坑檢查點」。

## 安全邊界

進版控的記憶層禁止寫入 token、密碼、連線字串或個資；環境變數只記名稱不記值。教訓與規則衝突時以規則檔與決策紀錄為準，當下保留待驗證標記並在下次相關寫入時修正。
