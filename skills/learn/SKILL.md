# /learn — 手動深度回顧與記憶維護

日常記憶擷取與局部整理已內化在常駐規則、任務收尾流程與平台 hooks。本技能只在使用者要求完整回顧，或需要跨多筆記憶／跨專案整理時使用。

## 觸發情境

- 使用者明確要求回顧本次對話、整理記憶或保存經驗。
- 需要跨多個記憶檔去重、合併、清理或校準。
- 發現同類教訓已達升級門檻，需要提出規則、skill、playbook 或全域記憶提案。

## 流程

### 1. 蒐集範圍

讀取相關對話、工作日誌、記憶索引、`overview.md` 與 `DECISIONS.md`。只掃描與本次主題相關的檔案；使用者要求跨專案回顧時才擴大範圍。

### 2. 整理與分類

- 先查 `MEMORY.md`，相同主題優先合併或更新，不建立重複檔案。
- 驗證引用的檔案、指令與行為；過時或被證偽的內容提出刪除或修正。
- 保留最新且已驗證的事實；無法確認的內容標記「待驗證」。
- 被糾正的客觀技術錯誤 → `pitfall`。
- 方案轉彎或多選一拍板 → `DECISIONS.md`。
- 工作方式或偏好 → `feedback`。
- 專案歷史脈絡與架構緣由 → `overview.md`。
- 其他可重用背景 → `user`／`project`／`reference`。
- 一次性資訊、repo 已記錄內容或沒有後續價值的內容 → 不記。

### 3. 位置判斷

- 跨專案通用 → 全域記憶層。
- 僅限本專案 → 專案記憶層。
- 不確定 → 先放專案層；至少兩個獨立專案有相同證據，才提出升級全域的提案。

### 4. 核准與寫入

- 記憶檔與 `DECISIONS.md` 的一般新增、合併、修正可直接寫入。
- 新增或修改規則、skill、playbook、全域記憶前，逐項列出證據與提案，經使用者核准才寫入。
- 新增／刪除記憶檔時同步更新 `MEMORY.md` 索引。
- 進版控的記憶層不得寫入秘密、token、密碼、連線字串或個資。

### 5. 回報

回報整理了哪些檔案、哪些提案獲核准，以及未處理的項目。若有寫入，末尾回報「已沉澱：<摘要>（<檔名>）」；若沒有新知識，回報「無可沉澱：<理由>」。
