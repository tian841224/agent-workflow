# /evolve — 精煉引擎(自我學習框架:精煉階段)

本技能是自我學習框架的**精煉階段**:把累積的原始知識(/learn 擷取的記憶、坑洞、決策 + 工作日誌)提煉成更高階的資產——規則、技能、整併後的記憶。讀素材 → 找模式 → 提案 → 核准 → 寫入。**所有變更一律核准制,未核准不落盤。**

真正的即時學習由 `/learn`(任務中隨時擷取)與每個任務收尾的 know-how 沉澱三問負責,兩者都已經是每次對話都會做的事,不需要等這支 skill。這支 skill 做的是**跨多筆記憶的整理**——去重、升級、校準——這類模式辨識本來就適合累積一定量後一次處理,執行時機由使用者或模型視需要決定,不掛在任何週期或到期提醒上。

## 步驟

### 1. 蒐集素材(涵蓋三類知識)

- 讀近 7 天的 `~/.claude/logs/*.md`(以檔名日期判斷)
- 讀 `~/.claude/memory/MEMORY.md` 索引,按需讀各記憶檔
- 讀當前專案 auto-memory 的 MEMORY.md 索引,按需讀各記憶檔,**含 pitfall 類**(路徑見系統提示的 Memory 區段)
- 讀當前專案的 `overview.md`(若存在),確認專案脈絡與高風險區描述是否仍與現況相符
- 讀當前專案的 `DECISIONS.md`(若存在)
- 讀 `~/.claude/USER.md`,確認畫像是否過時

### 2. 分析並產出提案

每項提案必須附**證據**(出自哪天日誌、哪筆記憶、哪筆決策),分七類:

1. **新規則**:反覆出現的糾正或偏好 → 建議新增至全域或專案 CLAUDE.md 的具體條文
2. **新技能**:重複執行的多步流程 → 生成完整 SKILL.md(name/description frontmatter + 步驟);全域放 `~/.claude/skills/<name>/`,專案放 `<project>/.claude/skills/<name>/`
3. **記憶整併**:重複、過時、矛盾的記憶 → 合併或刪除(pitfall 同樣適用:重複坑洞合併、已失效的坑刪除)
4. **升級全域**:同類經驗(含 pitfall)出現在 ≥2 個專案的專案記憶 → 搬到 `~/.claude/memory/`
5. **坑洞→規則轉化**:同一個 pitfall 記了之後又再犯(日誌或對話中有再犯證據)→ 提案升級成 CLAUDE.md 強制規則或 hook,讓它從「被動記憶」變「主動防線」
6. **決策回顧**:掃 `DECISIONS.md`,找出已被後續發展推翻的決策(提案標記過時,附推翻它的後續決策/變更為證據);跨專案重複出現的同類決策模式 → 提案沉澱成通用慣例(全域記憶或規則)
7. **overview 校準**:專案 `overview.md` 是否仍與現況相符(架構是否已變、高風險區是否過時)、是否超過約 100 行需把細節下放成個別記憶檔(只留索引行)→ 提案具體修訂內容

沒有足夠證據就不要硬提案;寧缺勿濫。

### 3. 逐項核准

用 AskUserQuestion(或逐條列出)讓使用者逐項決定,**僅執行核准項**。

### 4. 寫入與收尾

- 執行核准的變更(檔案一律 UTF-8)
- 視需要更新 `~/.claude/memory/last-review.txt` 為今天(yyyy-MM-dd),留作下次整理時參考的時間點,純備忘用途,不是任何機制的觸發依據
- 在當日日誌追加一行整理結論:`- HH:mm [evolve] 整理完成:<N 項提案,M 項核准,摘要>`

### 5. 無提案時

回報「目前無需調整」即可,不必為了湊數而硬提案。
