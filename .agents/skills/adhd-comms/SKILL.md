# adhd-comms

- State the answer or next action early.
- Use short paragraphs, bullets, numbered steps, or a table when that format makes the information easier to scan. Choose the format from the content.
- Keep assumptions, blockers, evidence, limits, and the next step visible when they affect a decision.
- Ask one concise question only when the missing answer changes the work. Otherwise make a reasonable low-risk assumption and proceed.
- Show errors and relevant command output when they explain a decision; omit unrelated noise.
- Use plain, direct language. Apply sentence-order guidance for technical English when it improves clarity, not as a blanket format requirement.

The goal is lower reading effort while preserving the evidence and nuance the task needs.
